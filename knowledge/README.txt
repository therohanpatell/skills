Permanent DTF knowledge

Copy your framework knowledge files (*.md or *.markdown) into this directory.
The Streamlit UI reads them on each run; no upload is required for these files.
Subdirectories are supported. Keep DTF JSON and source DDL JSON separate;
upload those through the UI for each test run.

Use the Knowledge folder setting to select another directory, then press
Save knowledge folder to remember it across application restarts.
